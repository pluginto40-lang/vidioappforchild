# 비공개 테스트(테스터 모집) 자료

"우리 아이 맞춤 영상"을 Google Play에 정식 출시하기 전에 거쳐야 하는 **비공개 테스트**를 준비하는 자료예요.

> ⚠️ **이 저장소는 공개돼 있어요.** 테스터의 이름, 이메일, 전화번호, 설문 답변은 **절대 이 폴더(저장소)에 적지 마세요.**
> 테스터 명단은 내 구글 드라이브의 비공개 스프레드시트나 Play Console 안에만 보관하세요.

---

## 1. 꼭 지켜야 하는 규칙 (Google 공식 도움말 기준)

2026년 11월 11일에 아래 공식 페이지를 직접 읽고 정리했어요. 규칙은 바뀔 수 있으니 신청 직전에 한 번 더 확인하세요.

- 공식 출처 ①: [신규 개인 개발자 계정의 앱 테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko) (영어판: [answer/14151465](https://support.google.com/googleplay/android-developer/answer/14151465))
- 공식 출처 ②: [공개·비공개·내부 테스트 설정하기](https://support.google.com/googleplay/android-developer/answer/9845334?hl=ko)

| 항목 | 공식 내용 | 출처 |
|---|---|---|
| 누구에게 적용? | **2023년 11월 13일 이후에 만든 개인 개발자 계정** | ① |
| 테스터 수 | **최소 12명** | ① |
| 기간 | 출시 권한을 신청하는 그 시점에 12명 이상이 테스트에 참여 중이어야 하고, 그 사람들이 **바로 앞 14일 동안 끊김 없이** 참여 중이어야 해요 | ① |
| 중간에 빠지면? | 14일이 안 돼서 참여를 취소한 사람은 **숫자에 안 들어가요.** 나갔다가 다시 들어오면 그 사람의 14일은 **처음부터 다시** 세요 | ① (자주 묻는 질문) |
| 실제로 써야 하나? | 구글은 "테스터들이 기능을 최대한 많이 써 보도록 권하라"고 해요. 참여자가 12명 미만이거나 **"테스터 참여가 부족하면"** 테스트를 더 하라는 답이 올 수 있어요. 몇 번 써야 하는지 숫자 기준은 **공식 페이지에 없어요** | ① |
| 테스터 추가 방법 | **이메일 목록** 또는 **구글 그룹** 두 가지 | ② |
| 테스터 참여 방법 | 운영자가 보낸 **참여 링크(opt-in 링크)** 를 열고 직접 "테스터 되기"를 눌러야 해요. 링크는 앱을 테스트 트랙에 처음 올린 뒤 **몇 시간 지나야** 생길 수 있어요 | ② |
| 필요한 계정 | 테스터는 **구글 계정**이 있어야 해요 | ② |
| 리뷰 | 테스트 버전에는 Play 스토어 공개 리뷰를 못 남겨요. 따로 의견 받을 창구(이메일, 설문 등)를 만들라고 권해요 | ② |
| 출시 권한 심사 기간 | 보통 **7일 이내**, 가끔 더 걸릴 수 있어요. 끝나면 이메일이 와요 | ① |

### 출시 권한 신청서에서 묻는 것 (공식 페이지 ① 기준, 실제 문구는 조금 다를 수 있어요)

Play Console 대시보드 → "프로덕션 액세스 신청(Apply for production)"에서 세 부분을 써요.

**① 비공개 테스트에 대해**
1. 테스터 모집이 얼마나 쉬웠나요? (보기 중 선택)
2. 테스터들이 앱을 어떻게 썼나요? 모든 기능을 써 봤나요? 실제 출시 후 사용자와 비슷하게 썼나요? 다른 점은?
3. 테스터 의견을 요약하고, 의견을 어떻게 모았는지 적어 주세요.

**② 앱에 대해** (공개되지 않고, 승인 여부에도 영향 없다고 해요)
4. 대상 사용자는 누구인가요? (최대한 구체적으로)
5. 이 앱이 사용자에게 주는 가치는?
6. 첫해 예상 설치 수는?

**③ 출시 준비에 대해**
7. 테스트에서 배운 것을 바탕으로 앱을 어떻게 고쳤나요?
8. 출시 준비가 됐다고 어떻게 판단했나요?

> 신청서 작성 중 "취소"를 누르거나 "다음/신청" 없이 나가면 저장이 안 돼요. 미리 메모장에 써 두고 붙여 넣으세요. 답 모으는 법은 [운영-체크리스트.md](운영-체크리스트.md)에 있어요.

### 블로그·커뮤니티에서 도는 이야기 (공식 확인 안 됨)

아래는 공식 페이지에서 확인되지 않은 내용이에요. 참고만 하세요.

- "예전에는 테스터가 20명이었다가 12명으로 줄었다" → 지금 공식 페이지에는 **12명**만 나와 있고, 언제 바뀌었는지는 확인 못 했어요.
- "테스터가 매일 앱을 열어야 한다", "하루 몇 번 이상 써야 한다" → 공식 숫자 기준은 **없어요.** 다만 "참여가 부족하면" 거절될 수 있으니, 가끔이라도 실제로 써 달라고 부탁하는 게 안전해요.
- "12명 딱 맞추면 위험하니 여유 있게 모아라" → 공식 규칙은 아니지만, 중간에 빠지는 사람이 생기면 14일을 다시 세야 하니 **15~20명** 모으는 걸 추천해요.

## 3. 전체 흐름 한눈에 보기

1. 지인·육아 커뮤니티에 [모집 메시지](모집-메시지.md) 보내기 → **15명 이상** 이메일 받기 (저장소에 적지 않기!)
2. 앱 파일(AAB)이 준비되면 Play Console에서 **비공개 테스트 트랙** 만들고 테스터 이메일 등록
3. 참여 링크가 생기면 [참여 방법](참여-방법.md)과 함께 테스터에게 보내기
4. 12명 이상 참여 확인된 날 = **1일차**. 이날부터 14일 동안 아무도 빠지지 않게 챙기기
5. 7일차에 설문 보내기, 14일차 이후 출시 권한 신청
