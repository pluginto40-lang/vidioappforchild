# 테스터 모집 메시지

아래 글을 그대로 복사해서 쓰세요. `[ ]` 부분만 내 상황에 맞게 바꾸면 돼요.

> 💡 답장으로 받은 이메일은 **이 저장소에 적지 마세요.** (저장소가 공개돼 있어요) 내 구글 드라이브의 비공개 스프레드시트에만 모아 두세요.

---

## 1. 카카오톡 개인 메시지용 (짧게)

```
[이름]아, 부탁 하나만 해도 될까? 🙏

내가 아이 키우면서 직접 만든 앱이 있는데,
구글 플레이에 올리려면 테스터가 필요하대.

- 앱: "우리 아이 맞춤 영상" (아이 나이랑 고민 고르면 맞는 유튜브 영상 추천, 정한 편수만 보면 "오늘은 여기까지"로 끝나는 앱)
- 필요한 것: 안드로이드 폰 + 구글 계정 이메일(지메일)
- 할 일: 14일 동안 앱 지우지 말고, 가끔 한 번씩 열어 보기
- 이메일은 테스트 초대 보내는 데만 쓰고, 테스트 끝나면 지울게!

괜찮으면 플레이스토어에 로그인된 구글 이메일 알려줘 😊
(아이폰이면 아쉽지만 참여가 안 돼!)
```

## 2. 단톡방·육아 카페 글용 (조금 길게)

```
[제목] 아빠가 만든 육아 앱, 안드로이드 테스터 15분 모셔요 (14일)

안녕하세요. [아이 나이]살 아이 키우는 아빠예요.
아이에게 유튜브를 보여줄 때마다 "뭘 보여주지?", "언제 끄지?"가 고민이라
직접 작은 앱을 만들었어요. 구글 플레이에 정식으로 올리려면
테스터 12명 이상이 14일 동안 참여해야 해서 도움을 요청드려요 🙏

📱 앱 소개 – "우리 아이 맞춤 영상"
• 아이 나이대와 요즘 육아 고민(예: 양치 싫어해요, 잠자리 거부 등)을 고르면
  그에 맞는 유튜브 영상을 골라 보여줘요
• 미리 정한 편수만 보면 "오늘은 여기까지" 화면이 나와 시청이 자연스럽게 끝나요
• 회원가입 없이 바로 쓸 수 있어요
• 웹으로 먼저 구경해 보기: https://pluginto40-lang.github.io/vidioappforchild/

✅ 필요한 것
• 안드로이드 폰 (아이폰은 참여가 어려워요 😢)
• 플레이스토어에 로그인된 구글 계정 이메일 (지메일)
• 14일 동안 앱을 지우지 않고, 가끔(이틀에 한 번쯤) 열어서 써 보기
• 마지막에 짧은 설문(5문항, 2~3분) 답해 주시면 큰 도움이 돼요

🔒 개인정보 안내
• 받은 이메일은 구글 플레이 테스트 초대를 보내는 데에만 써요
• 다른 곳에 공유하거나 광고에 쓰지 않아요
• 테스트가 끝나면 제 명단에서 지워요
• 이메일은 댓글 말고 [쪽지 / 1:1 채팅 / 오픈채팅 링크]로 보내 주세요

참여해 주시는 분께는 진심으로 감사드리고,
써 보시고 불편한 점을 솔직하게 알려주시면 더 좋은 앱으로 다듬을게요.
감사합니다!
```

## 보낼 때 팁

- **15명 이상** 모으세요. 중간에 앱을 지우거나 빠지는 분이 생기면 14일을 다시 세야 해요.
- 카페 글은 **카페 규칙(홍보 금지 여부)** 을 먼저 확인하세요. 필요하면 운영자에게 미리 물어보세요.
- 카페·단톡방에서는 **댓글로 이메일을 받지 마세요.** 다른 사람에게 다 보여요. 쪽지나 1:1 채팅으로 받으세요.
- 이메일이 플레이스토어에 로그인된 계정과 **같은지** 꼭 한 번 더 물어보세요. 다르면 초대가 안 보여요.
