우리 아이 맞춤 영상

개인정보처리방침

이 앱은 회원가입이 없고, 개인정보를 모으는 서버도 없어요. 무엇이 어디에 저장되고, 어떤 외부 서비스와 연결되는지 그대로 적었어요.

1. 이 앱에서 고르는 정보와 저장 위치

추천을 위해 보호자가 아래 내용을 골라요.

  • 아이 나이대 (예: 12~24개월)
  • 아이 성별 — '선택 안 함'을 골라도 되고, 추천에는 쓰지 않아요.
  • 요즘 어려운 점, 아이에게 바라는 점
  • '기타' 칸에 직접 적은 글

이 내용은 사용하는 기기의 브라우저 저장공간(localStorage)에만 저장되고, 운영자나 다른 곳으로 보내지지 않아요. 운영자는 이 내용을 볼 수 없어요.

'기타' 칸에는 아이 이름, 연락처처럼 누구인지 알 수 있는 내용을 적지 말아 주세요.

2. 저장된 답 지우기

  • 추천 화면 오른쪽 위 '다시 고르기'를 누르고 끝까지 새로 고르면, 이전 답은 새 답으로 바뀌어요.
  • 저장된 답을 완전히 지우려면 브라우저(예: Chrome) 설정에서 이 앱 주소의 사이트 데이터를 삭제하거나, 브라우저 데이터 전체를 삭제해 주세요.

3. 연결되는 외부 서비스

앱을 쓰는 동안 아래 서비스에서 화면에 필요한 것을 불러와요. 이때 기기의 IP 주소, 브라우저 정보 같은 접속 정보가 각 서비스에 전달될 수 있어요.

  • YouTube 영상 재생 — 영상은 YouTube 공식 플레이어(개인정보 보호 강화 모드, youtube-nocookie.com)로 재생돼요. 영상을 틀면 YouTube·Google이 시청 정보 등을 수집할 수 있고, 이때는 Google 개인정보처리방침이 적용돼요. 영상과 영상 안의 광고는 YouTube가 제공해요.
  • 영상 미리보기 그림 — 추천 목록의 미리보기 그림은 YouTube 이미지 서버(i.ytimg.com)에서 불러와요.
  • 글꼴 — 화면 글꼴(Pretendard)은 jsDelivr(cdn.jsdelivr.net)에서 불러와요.
  • 웹 호스팅 — 앱 화면 파일을 보내 주는 웹 호스팅 업체가 접속 시각, IP 주소, 브라우저 정보 같은 접속 기록을 남길 수 있어요. 운영자는 이 기록으로 이용자를 찾아내거나 광고·분석에 쓰지 않아요.

이 앱에는 별도의 광고, 이용 분석 도구, 로그인 기능이 없어요. 운영자가 다른 회사에 개인정보를 제공하거나 처리를 맡기는 일도 없어요.

4. 아동 개인정보

이 앱은 부모·보호자가 사용하도록 만들었어요. 보호자가 영상을 골라 아이와 함께 보는 것을 전제로 해요.

아이의 이름, 생년월일, 사진, 연락처처럼 아이가 누구인지 알 수 있는 정보는 받지 않아요. 나이대와 성별은 기기 안에만 저장돼요.

5. 방침이 바뀔 때

로그인, 서버 저장, 이용 분석 같은 기능이 생기면 이 방침을 먼저 고치고, 바뀐 내용과 날짜를 이 페이지에 알려 드려요.
